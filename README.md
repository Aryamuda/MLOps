# Praktikum MLOps

Repositori ini berisi materi dan pengerjaan praktikum MLOps. Setiap hands-on
disimpan dalam folder terpisah agar kode, hasil eksperimen, dan dokumentasinya
tertata.

## Hands-on 1 — Pelacakan Eksperimen dengan MLflow

Folder [`Hands-on-1/`](Hands-on-1/) berisi implementasi eksperimen klasifikasi
digit menggunakan PyTorch, MLflow, dan DVC. Di dalamnya terdapat kode untuk
menyiapkan data, melatih dan membandingkan model, mendaftarkan model, serta
membuat laporan.

- Panduan menjalankan proyek: [`Hands-on-1/README.md`](Hands-on-1/README.md)
- Tangkapan layar MLflow: `Hands-on-1/images/`
